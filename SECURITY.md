# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `1.0.0-alpha1` | :white_check_mark: |
| < `1.0.0-alpha1` | :x: |

## Reporting a Vulnerability

We take the security of NovaFiles seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report
Please **do not** report security vulnerabilities through public GitHub Issues.

Instead, please report security concerns via one of the following methods:
1. **GitHub Security Advisory**: Go to the **Security** tab of this repository on GitHub and select **Report a vulnerability** to submit a confidential report.
2. If confidential advisories are not enabled, please open an issue requesting a private communication channel before disclosing details.

### Information to Include
To help us investigate and resolve the issue quickly, please include:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept code/instructions.
- The affected component, file, or feature.
- Android OS version and device model used for testing.
- Any potential impact or exploitation scenarios.

### Disclosure Timeline
- We will acknowledge receipt of your vulnerability report within 72 hours.
- We will provide regular updates regarding our assessment and fix progress.
- Once a fix is verified and deployed in an update, public release notes and credit will be published in accordance with coordinated disclosure practices.
